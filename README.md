## 中文说明


### 🐾 这是什么？


**Miao Today** 是一款专为"远距离家庭关怀"设计的应用。核心想法很简单：


> 传统报平安太刻意——打电话怕打扰，发消息怕麻烦。**云养猫把报平安变成一件轻松有趣的事。**


父母每天喂喂猫、撸撸猫，子女看到猫咪状态就知道爸妈今天还好。连续 3 天没有喂猫？子女会立即收到异常提醒。


### ✨ 产品亮点


- **小猫今天好** — 父母喂猫 = 子女安心，零压力的平安信号
- **12 种猫咪品种** — 橘猫、英短、布偶、暹罗、曼基康矮脚……总有一只适合爸妈
- **AI 健康助手** — 根据血压血糖数据智能对话，给出贴心建议
- **三级预警守护** — 48 小时留意提醒，72 小时异常警报，全自动
- **健康全管理** — 血压、血糖、用药、就医提醒一站搞定
