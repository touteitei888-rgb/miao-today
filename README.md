## 🐾 这是什么？ / What is this?

**小猫今天好（Miao Today）** 是一款专为"远距离家庭关怀"设计的应用。

**Miao Today** is an app designed for long-distance family care.

> 传统报平安太刻意——打电话怕打扰，发消息怕麻烦。**养只虚拟猫，把报平安变成一件轻松有趣的事。**
>
> Traditional check-ins feel forced — phone calls are intrusive, messages are a hassle. **Raise a virtual cat together, and turn check-ins into something fun and effortless.**

父母每天喂喂猫、撸撸猫，子女看到猫咪状态就知道爸妈今天还好。连续 3 天没有喂猫？子女会立即收到异常提醒。

Parents feed and pet the cat daily, while children see the cat's status to know Mom and Dad are okay. No feeding for 3 days? Children get an instant alert.

## 🎯 核心功能 / Core Features

### 🐱 云养猫（父母端） / Cloud Cat (Parent Side)

- 12 种猫咪品种可选，每只都有专属二次元形象
- 12 cat breeds with unique anime-style artwork
- 喂食、喂水、摸摸、逗猫棒、洗澡、送礼物等多种互动
- Feed, water, pet, teaser wand, bath, send gifts and more
- 猫咪状态随时间自然衰减，真实模拟养猫体验
- Cat stats decay naturally over time for a realistic pet experience
- 连续喂猫 = 连续报平安，记录陪伴天数
- Consecutive feeding days = consecutive safe check-ins

### 🛡️ 安心守护（子女端） / Peace of Mind (Child Side)

- **三级预警机制**：安全 / 留意（48h）/ 异常（72h）
- **3-Level Alerts**: Safe / Notice (48h) / Alert (72h)
- **弹窗预警卡片**：异常时第一时间弹出醒目提醒
- **Pop-up Alert Cards**: eye-catching warning on anomalies
- 猫咪状态、健康数据一眼掌握
- Cat status and health data at a glance
- 子女可送小鱼干、猫条、毛球玩具给爸妈的猫
- Children can send dried fish, cat sticks, and toys to parents' cats

### 🩺 健康管理 / Health Management

- 血压记录 + 趋势图，自动识别偏高/临界
- Blood pressure logging + trend charts, auto-detects elevated/critical
- 血糖记录 + 趋势图，支持空腹/餐前/餐后
- Blood sugar logging + trend charts, supports fasting/pre-meal/post-meal
- 用药提醒，一键标记已服
- Medication reminders with one-tap confirmation
- 就医提醒管理
- Doctor appointment management

### 🤖 AI 小助手 / AI Assistant

- **健康小助手**：根据血压血糖数据，智能对话给出建议
- **Health Assistant**: smart conversational advice based on BP/sugar data
- **就医小助手**：帮你准备好要问医生的问题
- **Doctor Visit Assistant**: prepares questions to ask your doctor
- 多轮对话交互，不是冰冷的建议列表
- Multi-turn dialogue, not a cold suggestion list
