## 中文说明

### 🐾 这是什么？

**Miao Today** 是一款专为"远距离家庭关怀"设计的应用。核心想法很简单：

> 传统报平安太刻意——打电话怕打扰，发消息怕麻烦。**云养猫把报平安变成一件轻松有趣的事。**

父母每天喂喂猫、撸撸猫，子女看到猫咪状态就知道爸妈今天还好。连续 3 天没有喂猫？子女会立即收到异常提醒。

### ✨ 产品亮点

- **小猫今天好** — 父母喂猫 = 子女安心，零压力的平安信号
- **12 种猫咪品种** — 橘猫、英短、布偶、暹罗、曼基康矮脚……总有一只适合爸妈
- **AI 健康助手** — 根据血压血糖数据智能对话，给出贴心建议
- **三级预警守护** — 48 小时留意提醒，72 小时异常警报，全自动
- **健康全管理** — 血压、血糖、用药、就医提醒一站搞定
- **纯前端零安装** — 打开链接就能用，不需要下载任何 App

### 🎯 核心功能

#### 🐱 云养猫（父母端）
- 12 种猫咪品种可选，每只都有专属二次元形象
- 喂食、喂水、摸摸、逗猫棒、洗澡、送礼物等多种互动
- 猫咪状态随时间自然衰减，真实模拟养猫体验
- 连续喂猫 = 连续报平安，记录陪伴天数

#### 🛡️ 安心守护（子女端）
- **三级预警机制**：安全 / 留意（48h）/ 异常（72h）
- **弹窗预警卡片**：异常时第一时间弹出醒目提醒
- 猫咪状态、健康数据一眼掌握
- 子女可送小鱼干、猫条、毛球玩具给爸妈的猫

#### 🩺 健康管理
- 血压记录 + 趋势图，自动识别偏高/临界
- 血糖记录 + 趋势图，支持空腹/餐前/餐后
- 用药提醒，一键标记已服
- 就医提醒管理

#### 🤖 AI 小助手
- **健康小助手**：根据血压血糖数据，智能对话给出建议
- **就医小助手**：帮你准备好要问医生的问题
- 多轮对话交互，不是冰冷的建议列表

### 🧱 技术栈

- **React 19** + **TypeScript**
- **Vite** 构建
- **Tailwind CSS** 样式
- **LocalStorage** 本地数据持久化
- 零后端依赖，纯前端运行

### 📱 双端切换

应用内置"父母端 / 子女端"切换，可直接在右上角切换角色体验两端功能：

- **父母端**：我的猫 / 健康 / 贴心 / 动态 / 我的
- **子女端**：守护 / 爸妈健康 / 一起养猫 / 动态 / 我的

## English

### 🐾 What is this?

**Miao Today** is an app designed for long-distance family care. The core idea is simple:

> Traditional check-ins feel forced — phone calls are intrusive, messages are a hassle. **Cloud Cat turns check-ins into something fun and effortless.**

Parents feed and pet the cat daily, while children see the cat's status to know Mom and Dad are okay. No feeding for 3 days? Children get an instant alert.

### ✨ Highlights

- **Miao Today (小猫今天好)** — Parent feeds cat = child's peace of mind, zero-stress safety signal
- **12 Cat Breeds** — Orange, British Shorthair, Ragdoll, Siamese, Munchkin… find the perfect match
- **AI Health Assistant** — Smart conversational advice based on blood pressure & glucose data
- **3-Level Alert System** — 48h notice, 72h alert, fully automatic
- **Full Health Management** — Blood pressure, glucose, medication, doctor visits all in one place
- **Zero Install** — Works in any browser, no app download needed

### 🎯 Core Features

#### 🐱 Cloud Cat (Parent Side)
- 12 cat breeds with unique anime-style artwork
- Feed, water, pet, teaser wand, bath, send gifts and more
- Cat stats decay naturally over time for a realistic pet experience
- Consecutive feeding days = consecutive safe check-ins

#### 🛡️ Peace of Mind (Child Side)
- **3-Level Alerts**: Safe / Notice (48h) / Alert (72h)
- **Pop-up Alert Cards**: eye-catching warning on anomalies
- Cat status and health data at a glance
- Children can send dried fish, cat sticks, and toys to parents' cats

#### 🩺 Health Management
- Blood pressure logging + trend charts, auto-detects elevated/critical
- Blood sugar logging + trend charts, supports fasting/pre-meal/post-meal
- Medication reminders with one-tap confirmation
- Doctor appointment management

#### 🤖 AI Assistant
- **Health Assistant**: smart conversational advice based on BP/sugar data
- **Doctor Visit Assistant**: prepares questions to ask your doctor
- Multi-turn dialogue, not a cold suggestion list

### 🧱 Tech Stack

- **React 19** + **TypeScript**
- **Vite** build tool
- **Tailwind CSS** styling
- **LocalStorage** for data persistence
- Zero backend dependency, fully client-side

### 📱 Dual-Mode Switch

Toggle between Parent and Child modes via the top-right switch:

- **Parent Mode**: My Cat / Health / Care / Moments / Profile
- **Child Mode**: Guardian / Parents' Health / Cat Together / Moments / Profile

Visit the [live demo](https://touteitei888-rgb.github.io/miao-today/) to use the app instantly — no registration, no download needed.
